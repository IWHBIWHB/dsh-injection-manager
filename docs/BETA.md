# BETA 试用脚本（约 8 分钟）

给愿意帮忙试用的朋友。目标不是"点一遍"，而是找出会让你在真实工作里愣住的地方。
全程不需要联网上传任何东西；插件不联网、不改工作区文件。

## 0. 安装（1 分钟）

DSH → 插件 → 添加插件，填 `dsh-injection-manager`；或终端：

```powershell
dsh plugin --profile desktop add dsh-injection-manager
```

装完刷新页面（首次安装不需要重启）。左侧出现「上下文注入」。

## 1. 看两个数字（2 分钟）

打开左侧「上下文注入」：

- 顶部写「新会话首轮 xx」与「可关闭 xx%」；把鼠标停上去，看它怎么解释这两个数。
- 进任意一个已有会话，点顶部新的「注入」标签：看「本会话已注入 / 新会话将注入 / 可关闭 / 上下文窗口」四个卡。
- **要判断的**：这四个数和你对这个会话的直觉差多少？有没有哪个数你完全不知道从哪来？

## 2. 关一套，再撤销（2 分钟）

- 管理页找一套你觉得"根本没用"的（一个 MCP server / 一个插件 / 一堆技能），把整行开关关掉。
- 看新会话首轮数字变化；点右下角/顶部的「撤销上一步」恢复。
- **要判断的**：关掉后数字变化符合预期吗？撤销可靠吗？有没有出现「开关关了但数字没变」？

## 3. 打开一项原文（1 分钟）

- 展开某一套，点「行内预览」，再点「查看内容」。
- **要判断的**：抽屉里的内容是不是你以为的那份？路径/来源对不对？有没有暴露你不想看到的东西？

## 4. 右侧栏与设置行（1 分钟）

- 打开右侧边栏的「上下文注入」标签：能否在窄栏里完成「看数 → 关一套」？
- 设置 → 通用设置 → 最下面「反馈」一行：点「复制诊断」，看剪贴板里是什么；点「报告问题」，看是否预填。

## 5. 报告（1 分钟）

任何一条不符合预期，直接：设置 → 反馈 →「报告问题」；诊断里只有版本、槽位注册与策略计数，
没有路径、会话 id、对话内容。或者把「复制诊断」的内容贴到
[GitHub issue](https://github.com/IWHBIWHB/dsh-injection-manager/issues/new/choose)。

**最想收到的三类问题**：

1. 数字明显不对（尤其"本会话"与"新会话"混淆）；
2. 开关不生效、或生效时机与说明不符；
3. 某个入口没出现（面板/会话页/右侧栏/设置行），附上宿主版本。
