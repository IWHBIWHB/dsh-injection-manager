## 按优先级排的差距

1. **发布与收录**：2.3.0 发 npm + GitHub release；向官方精选目录提交条目（本轮已备好
   `market-entry.yml`）。没有这一步，前四层做得再好也不会被官方看见。
2. **真实用户反馈**：找 5 个装了 15+ 插件的人跑 `/inject` 与五个入口，收集失败/误解；尤其验证
   右侧栏在不同窗口宽度与多显示器下的表现。
3. **会话标签页的信息量**：目前只回答「带多少」，没有「哪些最值得关」的会话内结论；下一轮加一行
   「本会话最大的可关套件」并复用管理页的跳转。
4. **0.2.0 / 0.2.1 真机验证**：兼容性文档里这两档仍是「预期」，需要一台旧宿主或在 QA 里降级安装。
5. **客户端可维护性**：client.js 拆模块（宿主允许 client 目录多文件），并给 SessionView/SettingsCard
   补 DOM 级测试。
6. **性能回归门禁**：把 `/summary`、面板打开、五入口打开的耗时纳入 CI，超过基线 20% 直接失败。
