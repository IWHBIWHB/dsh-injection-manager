# 性能

一份 355 条目、27 个套件、230 个 REA 条目的真实快照，在 Edge（Chromium）无头模式下的实测。数字用于判断「有没有明显卡顿」，不是基准测试。

环境：Windows 11、Edge 当前版、视口 1200×860、数据来自本机 DSH 0.2.2-rc.3 的真实 `/summary`。

| 指标 | 实测 |
| --- | --- |
| 页面 `domContentLoaded` | 68–89 ms |
| 首次内容绘制（FCP） | 88–112 ms |
| 面板可交互（`.ci-grouphead` 出现） | 240–310 ms |
| 分组视图行数 | 27 行（全部渲染） |
| 展开最大套件（230 行）到可见 | 61–120 ms |
| 搜索「rea」到结果稳定 | 37–54 ms |
| 搜索后分组数 | 8 |

结论：不必引入虚拟列表。列表按套件折叠，展开最大套件时一次性渲染 230 行仍在 100 ms 量级；搜索用 `useDeferredValue` 让输入保持响应，过滤本身在 50 ms 内完成。

复现：`_research/polish-shots.mjs`（离线夹页，同一份真实快照；会把设置页、说明页、深色主题也截图）。
